## Syllabus RAG PROJECT
Retrieval-augmented QA over course syllabi with chunk-level indexing + citations.

### Run locally
pip install -r requirements.txt
python app/rag_mvp.py --docs ./docs --query "How many quizzes are dropped?" --top_k 5
